🪙 コインのもらい方・ガチャの確率

コインのもらい方

  • ワンタップ通知：1回 1コイン（1日30コインまで）
  • いろいろ送るボタン：1日20コインまで
    ・天気予報・占い：1回3コイン（それぞれ1日1回まで）
    ・チンチロ・ランダムワード・アナグラム：1回3コイン
    ・呼び出し：コインなし
  • その日はじめて送る：+10
  • 連続で送った日数：3日 +20・7日 +50・14日 +100・30日 +200・100日 +500・365日 +1000
  • バッジをもらう：+30（隠しバッジは +100）
  • ボタンがレベルアップ：+50
  • アナグラムで揃う：難易度C +20・B +50・A +100・S +200・SS +300・SSS +500

ガチャの確率：N 59.8%・R 28%・SR 10%・SSR 2%・シークレット 0.2%

天井：SSR が出ないまま50回まわすと、次は SSR 以上が確定

かぶったとき：かけらになります（N 1・R 3・SR 10・SSR 30・シークレット 50）。
交換に必要なかけら：N 10・R 30・SR 100・SSR 300

季節限定：春（3〜5月）・夏（6〜8月）・秋（9〜11月）・冬（12〜2月）のシリーズは、その季節だけガチャに出ます。

📖 使い方

見たいところを押すと開きます。はじめての人は「① はじめての準備」から読んでね。

🌱 ① はじめての準備

通知を送り合うには、おたがいのiPhoneに「Bark」アプリが必要です。

  1. App Store で Bark をインストールして開く
  2. 通知の許可を聞かれたら 許可 を押す
  3. アプリに出てくる https://api.day.app/〇〇〇/... というURLをコピーして、友達に送る
  4. 友達からも、同じように友達のURLをもらう
🔑 このURLは「あなたに通知を送るための合言葉」です。仲のいい友達にだけ教えてね。
👫 ② 友達を登録する
  1. 「送る」画面のいちばん下、⚙️ 設定 を押して開く
  2. 友達の名前を入れる（あだ名でOK）
  3. Bark キーの欄に、友達からもらったURLをそのまま貼り付け
  4. 天気予報も送りたいときは、住んでいる地域に「渋谷」「大阪市」などを入れて 検索 → 候補から選ぶ
  5. 友達を追加 を押したら完了！

あとから直したいときは、「送る相手」で友達を1人だけ選んでから 選択中の友達を編集 を押してね。

📲 ③ 通知を送る
  1. 「送る相手」で、送りたい友達をタップして選ぶ（オレンジ色で ✓ が付いたらOK）
    何人でも選べます。選んだ全員に同時に届くよ。👥 全員 で一気に選んだり外したりできます
  2. 上の絵文字ボタンを押すだけ！

押した回数だけ通知が届くので、連打もOK。ボタンの右上に「×3」のように回数が出ます。

送れたら、画面の右下に緑の ✓ が一瞬出ます。送れなかったときだけ、下に赤いメッセージが出ます。

絵文字ごとに通知の音がちがうので、いろいろ押して聞きくらべてみてね。

💡 相手には、通知のタイトルに絵文字だけが届きます。誰から来たかは、事前に「この絵文字は私」と決めておくと楽しいよ。
🎁 ④ いろいろ送るボタン
  • 🌤 天気予報
    相手の地域の今日の天気・気温・降水確率と、ひとことコメントが届きます。（友達の地域の登録が必要）
  • 🔮 占い
    今日のラッキーアイテム・ラッキーカラー・運勢がランダムで届きます。
  • 🎲 チンチロ
    サイコロ3つを振って、役が届きます。役が出なければ3回まで振り直し。2人以上に送ると、「送った内容」でいちばん強い人に 👑 が付きます。
    強い順：👑 ピンゾロ（1・1・1）＞ 🎰 ゾロ目 ＞ 🎉 シゴロ（4・5・6）＞ 目（2つそろって残りの数。6が最強）＞ 💨 目なし ＞ 💀 ヒフミ（1・2・3）
  • 🚨 呼び出し
    相手がマナーモードや集中モードでも、音を鳴らして知らせます。押すと確認が出るので、OKを押すと送られます。
    ※ 相手の iPhone で「設定 → 通知 → Bark → 重要な通知」をオンにしてもらう必要があります。オフだと、ふつうの通知として届きます。
  • 💬 ランダムワード
    右のプルダウンでタイトルを選んで 💬 を押すと、そのタイトルの本文からランダムに1つ届きます。「すべてのタイトルから」を選ぶと、タイトルもランダムです。言葉は「💬 ランダム」タブで作ります。
  • 🔀 アナグラム
    入力欄に言葉を入れて 🔀 を押すと、文字がバラバラに並びかわって届きます。たまたま元どおりに揃ったら 🎉 お祝いの通知になります。
    ふつう：文字を並べかえるだけ（青いベンチ → いチ青ベン）
    むずかしい：同じ文字が何回も出たり、出ない文字があったり（青いベンチ → ベベ青チ青）
    入力欄の下に、その言葉の難易度（C・B・A・S…）と「何回に1回揃うか」が出ます。同じ文字が多い言葉は揃いやすいので、難易度は低めになります。
💬 ⑤ ランダムワードを作る
  1. 上の 💬 ランダム タブを開く
  2. タイトルに通知の見出し（例：💪 がんばれ）を書く
  3. 本文に、届けたい言葉を1行に1つずつ書く
  4. もっと増やしたいときは ＋ タイトルを追加

送るときは「タイトルを1つ → そのタイトルの本文を1行」ランダムで選びます。書いた内容は自動で保存されるので、保存ボタンはありません。

☀️ ⑥ 毎朝の天気予報

毎朝決まった時間に、友達へ天気予報を自動で届けられます。

はじめに1回だけ、GitHub との連携が必要です（作った人がやればOK）。

  1. 「☀️ 天気」タブのいちばん下 🔑 GitHub 連携の設定 にアクセストークンを貼る
  2. 接続して GitHub の設定を読み込む を押す

あとは「☀️ 天気」タブで

  • 送る時刻と送る日（毎日 / 雨・雪の日だけ）を選ぶ
  • 送る相手にチェック（地域を登録した友達だけ選べます）
  • コメントを好きに書きかえる（1行に1つ、ランダムで選ばれます）
  • 「毎朝の天気通知」の スイッチをオン にする

コメントや時刻を変えたら、保存して GitHub に反映 を押してね。今日の予報でプレビュー で、どんな通知になるか確認できます。

🌕 満月や七夕などの日は、「今日の小ネタ」がひとこと自動で付きます。
✏️ コメントに {name} と書くと友達の名前、{max} {min} は最高・最低気温に変わります。
⏰ 届く時間は、設定より数分〜30分くらい遅れることがあります。
📊 ⑦ ログを見る

「📊 ログ」タブで、これまでに送った回数が見られます。

  • 合計と、絵文字ごとの回数
  • 月ごとのグラフ（‹ › で年を切りかえ、棒を押すと内訳）
  • 年月ごとの一覧（年月を押すとグラフにジャンプ）
  • アナグラムの記録（言葉ごと・難しさごとの送信回数、成功回数、何回目で成功したか）
  • 送った履歴（いつ・誰に・何を送ったか。連打は「×5」のようにまとまります）

友達からもらった通知の履歴は、Bark アプリの中で見られます。

回数は、送るのに成功したぶんだけ数えます。

🎁 ガチャと図鑑

送るとコイン 🪙がたまって、そのコインでガチャが回せます。タイトルの横の 🪙 コイン数 を押すとガチャ画面が開きます。

  • 1回 10コイン、10連 90コイン（10連は SR 以上が1つ確定）
  • 出たものは図鑑に集まります。全部で365種類！
  • 季節限定のシリーズは、その季節のあいだだけ出ます
  • かぶったらかけら 💠になって、かけらを集めると図鑑の好きなものと交換できます
  • SSR が50回出なかったら、次は確定（天井）
  • SSR 以上が出たら、選んでいる送る相手に自慢の通知が届きます

コインのもらい方は、ガチャ画面のいちばん下に書いてあります。

🏅 ⑧ バッジとレベル

バッジ：送った回数・続けた日数・時間・チンチロの役などで、バッジがもらえます。全部で90個以上あって、中には条件がひみつの隠しバッジ（❓）も！

  • 「📊 ログ」タブの 🏅 バッジ で一覧が見られます
  • バッジを押すと、もらえる条件と、あと何回かが分かります
  • もらった瞬間は紙吹雪でお祝いします 🎉 選んでいる送る相手にも「🏅 バッジ獲得！」が届きます

レベル：絵文字ボタンは、送った回数で育ちます。

  • Lv.2（50回）背景に色がつく → Lv.3（200回）ふちが光る → Lv.4（500回）キラキラ → Lv.5（1000回）王冠👑
  • ボタンの左下にレベル、下の線が次のレベルまでのゲージです
  • レベルが上がると、相手に届く通知も 🐦✨ → ✨🐦✨ → 👑🐦👑 と豪華になります
📅「◯日連続」のバッジは、この機能を入れた日から数えます。
💾 ⑨ バックアップ

友達やログはこのiPhoneの中だけに保存されています。Safariのデータを消すと消えてしまうので、ときどきバックアップしてね。

  1. 「📊 ログ」タブのいちばん下 書き出し（ファイルに保存） を押す
  2. 出てきたメニューで "ファイル"に保存 → iCloud Drive を選んで保存

戻すときは 読み込み（上書き） を押して、保存したファイルを選びます。
読み込み（合算） は、今のログに回数を足したいとき用です。

🔔 1週間バックアップしていないと、「送る」画面の上にお知らせが出ます。
🏠 ⑩ ホーム画面に置く（おすすめ）
  1. Safari でこのページを開く
  2. 画面下の 共有ボタン（□に↑） を押す
  3. ホーム画面に追加 を選ぶ（名前は「呼び出し君」、ベルのアイコンになります）

アプリみたいにすぐ開けるようになります。

ホーム画面から開いたときは、下に引っぱっても更新できません。新しくなったページを読み込みたいときは、タイトルの横の 🔄 を押してね。

📱 ホーム画面から開いたページと、Safari で開いたページは、データ（友達・ログ・バッジなど）が別々に保存されます。移したいときは、バックアップの書き出し → 読み込みを使ってね。
💾 Safari は「7日以上開かなかったサイト」のデータを消すことがあります。ときどき開いて、バックアップもしておくと安心です。
❓ ⑪ 困ったときは

通知が届かない

  • 友達の Bark キー（URL）が正しいか、編集画面で確認してね
  • 相手の iPhone の「設定 → 通知 → Bark」で、通知がオンになっているか確認してね
  • おやすみモード・集中モード中は、通知が鳴らないことがあります

「送信失敗」と出る

  • キーが間違っているか、ネットにつながっていないかも。もう一度試してみてね

天気予報が「地域が未登録」と出る

  • ⚙️ 設定で友達を編集して、「住んでいる地域」を検索して選んでね

毎朝の天気予報が届かない

  • 「☀️ 天気」タブのスイッチがオンになっているか確認してね
  • その下に ❌ のメッセージが出ていたら、GitHub のトークンの期限切れかも。作り直して貼り直してね

友達やログが消えた

  • バックアップがあれば「📊 ログ」タブの 読み込み（上書き） で戻せます
